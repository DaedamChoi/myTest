# 토끼의 간식 바구니

휴대폰 브라우저에서 바로 하는 캐주얼 게임이에요. 설치는 필요 없어요.

- 화면을 손가락으로 좌우로 밀어서 토끼 바구니로 간식(🍬 🍓 🧁)을 받아요.
- ⭐ 별을 모아서 토끼의 털 색깔과 머리 장식(리본, 꽃 화관, 왕관 등)을 바꿀 수 있어요.
- 💖 하트를 받으면 목숨이 하나 늘고, 🌈 무지개를 받으면 6초 동안 피버 타임(점수 2배)이에요.
- 🐝 꿀벌과 ⛈️ 먹구름은 피하세요. 하트가 다 없어지면 게임이 끝나요.

## 실행 방법

`index.html` 파일 하나로 되어 있어요. 휴대폰에서 이 파일을 열거나, GitHub Pages로 올리면 링크만으로 바로 할 수 있어요.
기록과 꾸미기 아이템은 그 기기의 브라우저에 저장돼요.
